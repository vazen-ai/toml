# Contributing

Open an issue to propose a change. We build with AI coding tools, so a
well-defined issue is preferred to a pull request: describe the outcome you
need, why it matters and how to check it, and we will take it from there.

Keep examples and test data wholly fictional and newly authored. Do not submit
customer files, sanitised customer data or customer-derived geometry.

We edit this repository in our own source tree and publish it here. To take a
pull request, we port it into that tree, review it there and publish the result
back here, crediting you as a co-author.

You license your contribution under the terms [LICENSING.md](LICENSING.md) gives
each kind of file: Apache 2.0 for software and code, CC BY 4.0 for prose. Keep
existing attribution and licence notices intact.
