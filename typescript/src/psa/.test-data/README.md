# Test data

Every file here is made up. Five files were authored, one per ProSpace version,
to exercise that version's columns. The sixth, `v2024.4.0-two-planograms.psa`,
holds the cases a round trip must keep: two planograms, each with its own
Performance rows, a product placed as a tray in one and as a unit in the other,
and two products under one UPC. None is a customer's file or derived from one,
and none holds real products, retailers or geometry.
